= Architecture Decision Records

Architecture Decision Records preserve important FixMock decisions and their reasoning. GitHub Issues track delivery; ADRs explain why the project chose a direction.

== Status values

* `Proposed`: under review or awaiting implementation evidence.
* `Accepted`: adopted by the project.
* `Superseded`: replaced by a later ADR.
* `Rejected`: considered but not adopted.

== Naming

Use a four-digit sequence and short descriptive name, for example `0004-example-decision.adoc`.

== Required sections

Each ADR contains Status, Context, Decision, Consequences, Alternatives considered, and Verification when applicable.
