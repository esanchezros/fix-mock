# Security Policy

## Supported versions

| Version | Support |
| --- | --- |
| `main` / unreleased 0.2 | Active development |
| 0.1.x | Security support until 0.2.0 |

See the [support policy](docs/support-policy.adoc) for details.

## Reporting a vulnerability

Do not report a suspected vulnerability in a public GitHub Issue.

Send the report to `esanchezros@gmail.com` with the subject `FixMock security report`. Include:

- The affected version and usage mode.
- Reproduction steps or a minimal reproducer.
- The expected and observed impact.
- Any suggested mitigation.
- Whether the issue is already public or reported elsewhere.

Remove FIX credentials, counterparty identifiers, account data, and other sensitive session information. You should receive an acknowledgement within seven days.

## Security fixes

Confirmed vulnerabilities are fixed on supported lines when affected. Published Maven artifacts are immutable, so a corrected patch release replaces a vulnerable release in recommended-version documentation.
